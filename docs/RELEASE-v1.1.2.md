# 标签轮盘 Tab Orbit v1.1.2

本次更新让轮盘跟随已打开页面自动变化：**关闭页面后，对应卡片会从轮盘消失，不必手动刷新。** 自定义工作收藏继续保留，不会因为关掉页面而丢失。

## 自动更新，保留工作配置

- **自定义标签：**轮盘只显示仍打开的收藏；已关闭记录和原顺序保留在工具栏管理面板，重新打开相同完整网址后自动恢复，也可以手动移除。
- **所有标签：**自动同步新增、关闭及顺序变化，保持当前窗口优先、各窗口标签栏从左到右排列。新开页面无需收藏即可出现。
- **展开时也更新：**列表变化后重绘轮盘并清空已选状态，重新移动鼠标再选择，避免原地松手切到重排后的其他页面。
- **高频事件也能同步：**页面持续快速更新标题时，通知与查询不会被无限推迟；仅标题或图标变化会保留当前选择。
- **原有操作保留：**Ctrl + 右键、悬停放大、松开切换、顺时针排列、双圈固定角槽、滚轮分页和跨窗口切换继续使用，不增加权限。

已关闭的自定义记录仍计入最多 24 个收藏。轮盘隐藏卡片不等于删除收藏；新开的普通页面不会自动变成自定义收藏，自定义模式只恢复已有记录。

## 安装和升级

下载发布附件 `tab-orbit-v1.1.2.zip`，完整解压，在 `chrome://extensions/` 打开开发者模式，选择「加载已解压的扩展程序」，并选择**直接包含 `manifest.json` 的目录**。安装使用不需要 Node.js。

已有用户请保留原扩展与原加载目录，将新版文件复制到该目录，点击扩展卡片的「重新加载」，再刷新已经打开的网页。不要卸载后重装，以保留原收藏、顺序和模式。详细流程见 [安装与更新](https://github.com/woxicaocao/tab-orbit/blob/main/docs/INSTALLATION.md)。

## 使用边界与数据

自定义记录在本机保存，关闭网页不会删除这份配置；主动移除收藏后才不再保留对应恢复入口。图标仍从 Chrome 本地图标缓存读取，数据处理与权限范围没有新增。详见 [隐私与权限说明](https://github.com/woxicaocao/tab-orbit/blob/main/docs/PRIVACY.md)。

Chrome 设置页、新标签页、应用商店和内置 PDF 查看器等受限页面仍无法呼出轮盘，请从普通网页操作。工具栏原生弹出气泡、系统菜单与窗口外释放鼠标等行为仍需按实际环境人工验收。测试方式和范围见 [测试与发布验证](https://github.com/woxicaocao/tab-orbit/blob/main/README_TESTS.md)。
