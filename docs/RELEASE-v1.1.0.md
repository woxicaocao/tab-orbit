# 标签轮盘 Tab Orbit v1.1.0

按住 **Ctrl + 鼠标右键**呼出圆形标签轮盘，悬停放大，松开右键切换到对应页面。移回圆心或按 Esc 取消。

## 新增功能

- **自定义标签**：收藏和排序常用页面，最多 24 个；原有收藏保持不变。
- **所有标签**：自动显示各窗口已打开的标签，同网址的不同标签分别保留。
- **双圈布局**：标签较多时分为内外两圈，满额时为内圈 8 个、外圈 16 个。
- **滚轮分页**：所有标签超过 24 个时，按住右键滚动滚轮浏览其他页面；翻页后需要移动鼠标重新选择，避免原地松手误切。
- 支持跨窗口切换、搜索添加、调整顺序，以及关闭标签后重新打开相同网址自动恢复收藏位置。

## 安装和升级

下载 `tab-orbit-v1.1.0.zip`，解压后打开 `chrome://extensions/`，开启开发者模式，点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的目录。

升级时将新版运行文件覆盖到原安装目录，点击扩展管理页的“重新加载”，再刷新原先打开的网页。保留原安装路径和扩展，避免丢失本机收藏。

发布 ZIP 的根目录直接包含 `manifest.json`，同时附带中文 `INSTALL.txt`。ZIP 只包含扩展运行文件、图标和安装说明；源代码、文档和测试可从仓库查看。

浏览器工具栏原生弹出气泡的焦点关闭及窗口外释放鼠标行为仍需人工验收。Chrome 设置页、新标签页、应用商店等受限页面无法呼出轮盘。

## 数据与权限

收藏和模式仅保存在本机。扩展使用 `tabs`、`storage` 和 `favicon` 权限；图标通过 Chrome 本地 favicon 接口读取。轮盘使用 closed Shadow DOM，避免网页直接读取其他标签的标题和网址。
