# 隐私与权限说明

[← 返回项目首页](../README.md) · [安装指南](INSTALLATION.md) · [常见问题](FAQ.md)

本文描述 **Tab Orbit 1.1.2 当前代码的实际行为**。收藏和模式保存在当前 Chrome 用户配置的本机扩展存储中；插件没有自建服务器、账号系统、统计 SDK 或远程上传接口。

## 读取哪些数据？

为了展示和切换标签，插件通过 Chrome 扩展 API 读取当前可访问的已打开标签信息，包括标题、完整网址、图标元数据、标签 ID、窗口 ID、所在顺序和激活状态。

- **自定义模式：**只将手动添加的标签作为收藏长期保存；名称、网址等元数据随对应标签更新。轮盘只显示已打开的收藏，已关闭记录仍保存在本地和管理面板中，供重新打开相同完整网址后恢复原顺序。
- **所有标签模式：**根据已打开的标签生成并更新轮盘列表，运行期间保存在内存中；不会把所有标签自动变成长期收藏。
- **网页内交互：**内容脚本接收用于呼出、选择、翻页和取消轮盘的鼠标、指针和键盘事件，并管理弹层焦点。当前实现不采集网页正文、表单输入、密码、Cookie 或浏览历史记录。

## 数据保存在哪里？

| 数据 | 位置与用途 |
| --- | --- |
| 自定义收藏 | `chrome.storage.local`：保存标题、完整网址、图标元数据、收藏顺序、标签与窗口标识、会话标识和可用状态 |
| 显示模式 | `chrome.storage.local`：保存自定义 / 所有标签模式及已有设置 |
| 当前会话标识 | `chrome.storage.session`：区分浏览器或扩展会话，避免旧标签 ID 被复用后错误绑定 |
| 所有标签列表、轮盘实时列表、图标缓存 | 扩展运行时内存，用于显示和加快交互；重建后台或页面脚本时会重新获取 |

收藏保存的是**完整网址**，包含其路径、查询参数和片段，用于重新匹配已打开的页面。完整网址中若本身包含个人信息，这些内容也会随收藏保存在本地。

插件不使用 `chrome.storage.sync`，没有跨设备同步，也没有导入导出功能。本机浏览器配置的备份、共享或操作系统访问权限由使用者自行管理。

## 为什么需要这些权限？

| 声明 | 实际用途 |
| --- | --- |
| `tabs` | 读取标签标题、网址、图标和窗口信息，并激活目标标签；跨窗口切换时将目标窗口置前 |
| `storage` | 保存自定义收藏和模式，区分浏览器会话 |
| `favicon` | 读取 Chrome 本地 favicon 缓存中的图标 |
| 普通网页内容脚本，匹配 `<all_urls>` | 在支持的顶层网页上监听 Ctrl + 右键并显示轮盘；Chrome 受保护页面仍受浏览器限制，iframe 未注入 |

`<all_urls>` 是内容脚本的注入范围声明。它让手势可以在不同网站上使用；当前代码不扫描网页内容，也不把网页内容发送到外部。

## 图标会访问其他网站吗？

插件后台只读取 Chrome 自己的 `/_favicon/` 本地资源，将有效 PNG 以数据形式交给轮盘显示。读取失败时使用标题首字替代，**不直接请求网站提供的远程图标地址**。

插件本身没有远程上传逻辑。这不影响 Chrome 或你打开的网站各自原有的网络行为；本文只描述扩展代码。

## 网页能读到其他标签吗？

网页内轮盘和管理弹层使用**封闭 Shadow DOM**，引用由扩展内容脚本持有。其他网页脚本无法通过普通 DOM 查询读取其中显示的标签标题和网址；图标也不以其他网站地址的形式插入页面资源列表。

这属于对普通网页脚本的隔离，不是对浏览器开发者工具、其他获授权扩展或本机使用者的安全承诺。打开 DevTools 的调试接口仍可检查渲染内容。

## 无痕窗口

默认不在无痕窗口启用。只有你在 Chrome 扩展详情中手动允许后，扩展才会获得相应无痕环境的访问能力。

当前版本没有为无痕收藏设计独立、自动清除的存储区。**请勿把本地收藏视作无痕会话结束后会自动消失的数据**；手动收藏的完整网址可能继续保存在扩展本地存储中。

## 更新、移除与清理

正常更新时保留原扩展并重新加载，本地收藏与模式会继续保留。只在插件面板移除收藏，不会关闭对应标签，也不会清除网页自己的数据。

**关闭浏览器页面只会让该页从轮盘消失，不会删除自定义收藏数据。** 需要清除记录时，请在工具栏插件面板中移除对应收藏；它也会随之失去按原网址自动恢复的入口。

如果要清理收藏，可在工具栏插件面板中逐项移除。需要同时移除扩展和本地设置时，可以在 Chrome 扩展管理中卸载；卸载会清除该扩展的本地存储，包括收藏。因此**不要通过卸载来更新**；需要保留收藏时请参考 [更新指南](INSTALLATION.md#从旧版本更新保留收藏)。

如发现与本文不一致的行为，可通过 [GitHub Issues](https://github.com/woxicaocao/tab-orbit/issues) 反馈，避免提交包含私人标题、网址或浏览器配置的材料。
